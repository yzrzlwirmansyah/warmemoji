# warmemoji

[![make.fun](https://make.fun/badge/u-0xkianno-one-emoji-one-smile-5470751f.svg)](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f)

One emoji, one smile: a single smiling sun (🌞) — warm, universal, and
unmistakably a chosen pick rather than the default smiley. It greets a
stranger with sunshine and nothing else: no intimacy, no sarcasm, just a
friendly face in the sky.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

This writes the entry to `./out/entry.txt`.
